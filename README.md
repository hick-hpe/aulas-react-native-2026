# App Catálogo de Estudos

Aplicação desenvolvida em React Native utilizando Expo para demonstrar conceitos fundamentais de interfaces móveis.

O aplicativo apresenta um catálogo de estudos organizado em categorias, permitindo ao usuário navegar entre diferentes abas e visualizar listas de itens relacionados.

## Instalar
- Clone o repositório:
    ```bash
    git clone -b atv02 https://github.com/hick-hpe/aulas-react-native-2026/
    ```

- Instale as dependências:
    ```bash
    npm install
    ```

## Executar
Inicie servidor do `Expo`:
```bash
npx expo start
```
